# VlogMCP

MCP-сервер для AI-агентов, который превращает рабочие сессии разработчика в структурированные видеоотчёты.

## Идея

AI-агент управляет полным видеопродакшном: записывает экран, аннотирует события, монтирует клипы, накладывает объекты, генерирует озвучку — и публикует готовый ролик. Человек задаёт конфиг и нажимает старт.

## Ключевые принципы

**Два таймлайна, не один.** Лог событий записи (что происходило и когда) и монтажный таймлайн (как собрать финальное видео) — разные вещи с разными задачами. Смешивать их нельзя.

**Объектная модель, не слайды.** Финальное видео — это фоновый слой (клип, картинка или цвет) плюс объекты поверх (текст, изображения, блоки кода, мемы и т.д.). Нет понятия "слайд" — только слои.

**Брендинг — только чтение.** Шрифты, цвета, плашки, intro/outro, watermark задаются в конфиге администратором. AI читает и использует — не меняет.

**Обратная связь через превью.** AI видит результат каждого изменения через `preview_frame()` без полного рендера. Монтаж — итеративный цикл, а не слепой однопроходный процесс.

**Библиотека как словарь.** Мемы, SFX, стикеры, перебивки, музыка — отдельная коллекция готовых материалов, которую AI ищет по тегам и вставляет в таймлайн.

## Быстрый старт (для AI-агента)

```
1. project_create("Название")
2. record_start(project_id)
   → во время записи: log_event() для разметки
3. record_stop(project_id)
4. event_log_get(project_id)          ← анализируем что записалось
5. [генерация активов: tts, diagrams, code_diff, ...]
6. timeline_create(project_id, duration)
   → timeline_add_clip / add_text / add_image / add_meme / ...
7. preview_frame(project_id, at=30)   ← смотрим результат
   → корректируем таймлайн
8. render(project_id)
9. publish(project_id, platform)
```

Или через готовый сценарий:

```
scenario_devlog(project_id, raw_clip_id, sections=[...], author="Имя")
→ черновой таймлайн собран, AI дополняет деталями
```

## Внешние зависимости

- **ffmpeg** — запись экрана, монтаж, рендер (обязателен)
- **OpenAI API** — TTS, генерация изображений
- **ElevenLabs API** — TTS (fallback)
- **Telegram Bot API** — публикация
